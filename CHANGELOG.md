# Changelog

## 1.1.0 (2026-11-04)

**New**
- 8 new languages: Turkish, Ukrainian, Persian, Hindi, Urdu, Italian, Portuguese, Greek (off by default; turn them on in the Keyboards tab).
- **Change letter case** shortcut (`Ctrl+Alt+U`): UPPER CASE, then Sentence case, then lower case, one step per press.
- **Snippets**: save texts (email, phone, address...) with a title and paste them from a small menu (`Ctrl+Alt+S`). Stored only on your PC.
- **Preview before replacing** (off by default): shows the result first, Enter applies, Esc cancels.
- **Double-tap Shift or Ctrl** to run one conversion (off by default).
- **Undo up to 10 conversions** in a row.
- **History** tab with your recent conversions (saved on your PC only while the program runs and deleted when you quit it completely; can be turned off or cleared).
- First-run **welcome tour** with a box to try it in.
- Accent colors, new **Midnight** and **Sand** themes.
- New logo and a sharper taskbar icon. The Arabic interface is mirrored right-to-left. Choose programs to skip with a Browse window.
- Interface now in English, Arabic, German, French, Spanish and Russian.
- Optional **update check** (off by default). It only asks GitHub for the latest version number.
- Releases can be built on GitHub and code-signed with SignPath (see the README).

**Website**: Arabic version, changelog page, animated demo.

## 1.0.0

First public release: 6 languages, up to 10 shortcuts, undo, excluded programs, tray app, light/dark themes, English and Arabic interface.
